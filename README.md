# GRAB & LOG

Tool room inventory system — recreation of the Figma design.

## Files
- index.html
- style.css
- app.js

## GitHub Pages
1. Create a repo
2. Upload the three files
3. Settings → Pages → Deploy from branch `main` / root
4. Live at `https://USERNAME.github.io/REPO/`

## Usage
1. Open the site
2. Click **Sign in to inventory**
3. Use the tabs to filter tools
4. Click **BORROW TOOL** or **Dispose**
5. Sidebar switches between Inventory / Activity Logs / Alerts Desk / Operator Registry
6. Click **ALERT DESK** on the critical banner to open the Control Registry table
